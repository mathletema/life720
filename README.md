# Life 720

Life 720 is a full-stack application that consists of a server, a web client, and a mobile client (likely using React Native).

## Project Structure

- `/server`: Backend server code
- `/webclient`: Web client application
- `/client`: Mobile client application (possibly React Native)
- `/common`: Shared code between different parts of the application

## Prerequisites

- Node.js (version X.X.X or higher)
- npm (version X.X.X or higher)

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/your-username/life720.git
   cd life720
   ```

2. Set up the environment:
   ```
   source env.sh
   ```

3. Install dependencies:
   ```
   npm install
   ```

## Running the Application

### Server

To run the server:

```
cd server
npm start
```

### Web Client

To run the web client:

```
cd webclient/src/app
npm run dev
```

### Mobile Client

For instructions on running the mobile client, please refer to the documentation in the `/client` directory.

## API Testing

To test the API locally:

1. Start the server as described above.
2. Use tools like cURL, Postman, or the web client to send requests to the API endpoints.
